# Tests

This folder holds [`skill-load-test`](skill-load-test/SKILL.md), a test skill that confirms your AI tool loads skills.

Install it the same way as the other skills, then ask your AI tool: "Is the coach skills test working?" If the skill loaded, the AI replies with a line that starts with `COACH-SKILLS-LOADED`. Remove the test skill when you are done.

See [Confirm the install works](../README.md#confirm-the-install-works) in the README.
