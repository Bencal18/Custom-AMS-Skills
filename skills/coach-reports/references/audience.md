# What to show coaches and athletes

Last checked: 2026-10-02

## What it covers

This file says what to put in a report for a coach and what to put in a report for an athlete. The rules are design guidance from practice. They are not results from trials. Ask the user to adjust them to the team's habits and to the data policy of the organization.

## Method

Make one report for each audience. Start each report from the decision the reader makes. Then pick the fewest numbers that support it.

Robertson and colleagues (2017) discuss the types of data in monitoring systems, the analysis approaches, and the visualization and communication of results to stakeholders in team sport. Treat each as a choice that the user can change.

In a survey of 145 elite soccer practitioners, raw scores were the most preferred format (62.1 percent), ahead of standardized and composite scores, and 52.3 percent endorsed showing uncertainty (Asimakidis et al., 2026). In a survey of UK elite sport practitioners, 11 of 25 who used a monitoring system said athletes did not get enough feedback (Neupert et al., 2022). Neither study tested a report design.

### Build the coach view

The coach decides whom to talk to, and how to plan the next session. Include these items:

- A short list at the top of athletes whose results changed beyond the noise band, with the measure, the size of the change, and the date
- For each listed athlete, the raw value, the athlete's own baseline, the unit, the typical error, the noise band, and the smallest worthwhile change
- Each sub-score next to any composite score
- Coverage: how many athletes have data, out of how many are expected, and who is missing
- The date of each athlete's last value
- A short note that states the limits: the data shows a change, not a cause

Sort the list by size of change relative to the noise band, or by name. Do not sort by a color or a single score that hides the parts.

### Build the athlete view

The athlete decides how to act on their own numbers. Include these items:

- Only that athlete's data, with no teammate shown by name or rank
- Each measure against the athlete's own usual range, in plain words, for example `Your jump height this week is within your usual range`
- A trend of the athlete's own values over time, with the usual range shaded
- The raw value and the unit
- A way to see what the measure means and what to do if the athlete has a question or a concern

Do not show a color that means good or bad without a plain label. Do not use words that scare or diagnose. Do not show a score that the athlete cannot trace to the inputs.

### Compare the two views

| Item | Coach view | Athlete view |
|---|---|---|
| Scope | The group, with the athletes who changed first | One athlete |
| Comparison | Each athlete to that athlete's baseline | The athlete to their own usual range |
| Detail | Raw value, change, noise band, sub-scores | Raw value, trend, plain words |
| Missing data | Listed by athlete | Shown as no data, with the date of the last value |
| Language | Short, with numbers | Plain, with no diagnosis or ranking |

### Keep the data private

Athlete monitoring data is personal health data. Ask the user who is allowed to see each report. Send each athlete only that athlete's report. Check the organization's data policy and the laws that apply before you paste data into a cloud AI tool.

If any athletes are minors, remind the user to check the consent rules and the rules on parent or guardian access before a report goes out.

### Handle welfare concerns

Wellness forms can hold mood, stress, or free-text answers. If an answer suggests a mental-health or welfare concern, do not interpret it, score it, or put it in a report. Tell the user to follow their organization's referral process and involve appropriate staff.

## Common mistakes

These are the mistakes AI tools make most often when they build a report:

- Sending the coach dashboard to athletes. It shows teammates and rankings.
- Ranking athletes on one composite score, which hides which part changed
- Showing every athlete's every measure. The coach cannot find the few who need attention.
- Showing a change with no baseline or no noise band, so every small change looks like news
- Showing a squad average with no spread. Hopkins and colleagues (2009) advise showing the standard deviation, so readers can judge the size of differences and the spread between athletes.
- Hiding missing data. An athlete with no data looks the same as an athlete with a normal result.
- Writing a cause or a plan, for example `reduce load`. That is the practitioner's decision.
- Writing for researchers, with terms such as `z-score` and `ICC` and no definition
- Writing a long report. A report that nobody reads does not support a decision.

## Example request

> Make me a one-page weekly report for the head coach from the jump tests and the wellness forms, and a separate version I can send to each athlete.

Status: not tested.

## Check the result

Run these checks on both versions:

- Read the athlete version as one athlete. Confirm it has no teammate's name or data, and no ranking.
- Read the coach version as a coach with one minute. Confirm the top of the page tells you who to talk to, and why.
- Count the athletes in the report. Confirm it equals the roster, including those with no data.
